# PersonaClick iOS SDK — demo shop

A small shop app built from the PersonaClick iOS SDK's UI kit and its public methods: home with
instant search, categories and a recommender block, a category with filters and sorting, a product
page with recommendations, and search results. UIKit, no storyboards besides the launch screen.

The SDK comes from Swift Package Manager:
[`https://github.com/PersonaClick/ios-sdk`](https://github.com/PersonaClick/ios-sdk), version
3.37.1 or later, product `PersonaClick` (`import PersonaClick`).

There is no cart screen: "Add to cart" tracks the `cart` event and shows the kit's toast. Popups
from the dashboard are shown by the SDK as it does by default. Push is not set up, so the SDK
neither asks for the notification permission nor sends a push token.

## Running the demo

Built with Xcode 26. The app runs on iOS 12 and later, as the SDK does.

1. Open `DemoShop.xcodeproj`; Xcode fetches the SDK package.
2. Pick the `DemoShop` scheme and a simulator, then Run.

To run on a device, set your own team under Signing & Capabilities (the project carries the
PersonaClick one).

The project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from
[`project.yml`](project.yml). The generated project is committed, so XcodeGen is only needed when
you change the spec: edit `project.yml`, then run `xcodegen` in the repository root.

## Configuration

Everything that ties the app to a shop is in [`DemoShop/ShopConfig.swift`](DemoShop/ShopConfig.swift):

- `shopId` — your shop identifier from the dashboard;
- `homePopularCode`, `productSimilarCode`, `productRecentlyViewedCode` — recommender block codes;
- `storiesCode` — a stories block for home; empty, home shows no stories bar.

The home block runs an A/B test in the demo shop: segment B gets products, segment A an empty
block, which the kit hides. The SDK picks the segment when it starts, so relaunch the app to see
the other one.
